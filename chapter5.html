Chapter 5: Radical Expressions

Practice questions based on the chapter.

1. What is the value of √49?

√49 = 7 because 7² = 49.

2. Which expression is equal to √72 in simplest form?

√72 = √(36 × 2) = 6√2.

3. Simplify: √50

√50 = √(25 × 2) = 5√2.

4. What is √12 + √27?

√12 = 2√3 and √27 = 3√3. Therefore, 2√3 + 3√3 = 5√3.

5. What is 3√5 + 2√5?

Add the coefficients of the like radicals: 3√5 + 2√5 = 5√5.

6. Simplify: 7√3 − 2√3

7√3 − 2√3 = (7 − 2)√3 = 5√3.

7. What is √6 × √24?

√6 × √24 = √144 = 12.

8. What is √75 ÷ √3?

√75 ÷ √3 = √25 = 5.

9. Which number is irrational?

√16 = 4, √25 = 5, and √81 = 9 are rational. √10 is irrational because 10 is not a perfect square.

10. Which is greater: √50 or 7?

Since 7² = 49 and 50 > 49, √50 > √49 = 7.

11. If √x = 9, what is x?

Squaring both sides gives x = 9² = 81.

12. If √(x + 4) = 6, what is x?

x + 4 = 6² = 36, so x = 32.

13. Simplify: √(18x²), assuming x ≥ 0.

√(18x²) = √(9 × 2 × x²) = 3x√2, since x ≥ 0.

14. What is √8 + √18?

√8 = 2√2 and √18 = 3√2. Therefore, the sum is 5√2.

15. Simplify: (√5)² + (√3)²

(√5)² = 5 and (√3)² = 3. Therefore, 5 + 3 = 8.

16. Which expression is equal to √48 − √12?

√48 = 4√3 and √12 = 2√3. Therefore, 4√3 − 2√3 = 2√3.

17. If a = √2, what is a² + 3a?

a² = (√2)² = 2 and 3a = 3√2. Therefore, a² + 3a = 2 + 3√2.

18. What is √2 × (3√8)?

√2 × 3√8 = 3√16 = 3 × 4 = 12.

19. Which value of x makes √x = √64?

√64 = 8, so √x = 8. Therefore, x = 64.

20. Simplify: √45 + √20

√45 = 3√5 and √20 = 2√5. Therefore, 3√5 + 2√5 = 5√5.

21. If √x = 2√3, what is x?

x = (2√3)² = 4 × 3 = 12.

22. Which is the simplest form of √108?

√108 = √(36 × 3) = 6√3.

23. What is the value of (√7 + 2)(√7 − 2)?

Using (a + b)(a − b) = a² − b²: (√7)² − 2² = 7 − 4 = 3.

24. Which expression is equal to 1/√5?

Rationalizing the denominator: 1/√5 × √5/√5 = √5/5.

25. If √(x + 9) = √(2x − 3), what is x?

Equal square roots have equal radicands: x + 9 = 2x − 3. Therefore, x = 12.
