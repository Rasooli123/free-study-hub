MATHEMATICS 1

Logic

Chapter 15 · 25 Questions

1. Which of the following is a proposition?

A proposition is a statement that can be classified as either true or false. "7 is a prime number" has a definite truth value, so it is a proposition.

2. What is the truth value of the statement: "12 is an odd number"?

12 is divisible by 2, so it is even. Therefore, the statement is false.

3. If p is true, what is the truth value of NOT p?

The negation of a true proposition is false. Therefore, NOT p is false.

4. If p is false and q is true, what is the truth value of p AND q?

An AND statement is true only when both statements are true. Since p is false, p AND q is false.

5. If p is false and q is true, what is the truth value of p OR q?

An OR statement is true when at least one of its statements is true. Since q is true, p OR q is true.

6. Which of the following is the negation of: "x is greater than 5"?

The negation of x > 5 is x ≤ 5. This includes both x = 5 and values below 5.

7. If p is true and q is false, what is the truth value of p AND NOT q?

q is false, so NOT q is true. Therefore: true AND true = true.

8. The statement "If p, then q" is false in which case?

An implication "If p, then q" is false only when p is true but q is false.

9. What is the converse of: "If a number is divisible by 4, then it is even"?

The converse is formed by switching the hypothesis and conclusion: "If a number is even, then it is divisible by 4."

10. Which statement is always true?

Every multiple of 10 is also a multiple of 5. The other statements are not always true.

11. If p is true and q is true, what is the truth value of p OR q?

Since both p and q are true, their OR statement is true.

12. If p is false and q is false, what is the truth value of p OR q?

An OR statement is false only when both statements are false.

13. If p is true and q is false, what is the truth value of p AND q?

An AND statement requires both statements to be true. Since q is false, p AND q is false.

14. Which expression is equivalent to NOT (p AND q)?

By De Morgan's law: NOT (p AND q) = NOT p OR NOT q.

15. Which expression is equivalent to NOT (p OR q)?

By De Morgan's law: NOT (p OR q) = NOT p AND NOT q.

16. Which of the following is a tautology?

A tautology is always true. Either p is true or p is false, so one of p or NOT p must always be true.

17. Which of the following is a contradiction?

p and NOT p cannot both be true at the same time. Therefore, p AND NOT p is always false and is a contradiction.

18. If "If p, then q" is true and p is true, what must be true?

If p → q is true and p is true, q must also be true. Otherwise, the implication would be false.

19. Which statement is equivalent to: "If x is divisible by 6, then x is even"?

The contrapositive of "If p, then q" is "If NOT q, then NOT p." Therefore: If x is not even, then x is not divisible by 6.

20. Let p mean "x > 3" and q mean "x < 10". Which interval represents p AND q?

AND means both conditions must hold. Therefore, x must be greater than 3 and less than 10: 3 < x < 10.

21. Let p mean "x > 5" and q mean "x < 2". What is the truth value of p AND q for any real x?

No real number can be both greater than 5 and less than 2. Therefore, p AND q is always false.

22. Let p mean "x is even" and q mean "x is divisible by 3". What does p OR q mean?

OR means at least one of the two conditions is true. Therefore, x is even or x is divisible by 3.

23. Which number makes the statement "x is even AND x is greater than 5" true?

8 is even and 8 is greater than 5. Therefore, both conditions are satisfied.

24. If p → q is true and q is false, what must be the truth value of p?

An implication p → q is false when p is true and q is false. Since the implication is given as true and q is false, p must be false.

25. If p is false and q is true, what is the truth value of (NOT p) AND q?

p is false, so NOT p is true. q is also true. Therefore: true AND true = true.
