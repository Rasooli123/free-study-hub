MATHEMATICS 1

Operations

Chapter 13 · 25 Questions

1. Calculate: 18 ÷ 3 + 4 × 2

Division and multiplication come before addition: 18 ÷ 3 = 6 and 4 × 2 = 8. Therefore, 6 + 8 = 14.

2. If a ★ b = 2a + 3b, what is 4 ★ 5?

4 ★ 5 = 2(4) + 3(5) = 8 + 15 = 23.

3. Calculate: 24 − [6 + 2 × 5]

First, 2 × 5 = 10. Then 6 + 10 = 16. Finally, 24 − 16 = 8.

4. If a △ b = a² − b, what is 5 △ 7?

5 △ 7 = 5² − 7 = 25 − 7 = 18.

5. Which property is shown by 7 + 12 = 12 + 7?

Changing the order of the numbers does not change the sum. This is the commutative property.

6. Which expression is equivalent to 6(4 + 3)?

By the distributive property: 6(4 + 3) = 6 × 4 + 6 × 3.

7. If a ⊙ b = a + b + ab, what is 2 ⊙ 3?

2 ⊙ 3 = 2 + 3 + (2 × 3) = 5 + 6 = 11.

8. Calculate: 30 − 4(3 + 2)

3 + 2 = 5. Then 4 × 5 = 20. Finally, 30 − 20 = 10.

9. If a * b = 3a − 2b, what is 6 * 4?

6 * 4 = 3(6) − 2(4) = 18 − 8 = 10.

10. Which expression has the same value as 5(8 − 2)?

By the distributive property: 5(8 − 2) = 5 × 8 − 5 × 2.

11. If a △ b = 2a + b − 1, find 3 △ 5.

3 △ 5 = 2(3) + 5 − 1 = 6 + 5 − 1 = 10.

12. Calculate: 48 ÷ [2(4 + 2)]

4 + 2 = 6. Therefore, 2(6) = 12. Finally, 48 ÷ 12 = 4.

13. If x ◇ y = x² + y², what is 3 ◇ 4?

3 ◇ 4 = 3² + 4² = 9 + 16 = 25.

14. If a ⊗ b = a − 2b, which value of x satisfies 7 ⊗ x = 1?

7 ⊗ x = 7 − 2x. Therefore: 7 − 2x = 1, so 2x = 6 and x = 3.

15. Which statement is always true for addition?

Adding zero does not change a number. Therefore, a + 0 = a. This is the identity property of addition.

16. Calculate: 2 + 3 × (7 − 4)²

7 − 4 = 3. Then 3² = 9. Next, 3 × 9 = 27. Finally, 2 + 27 = 29.

17. If a ⊙ b = a + 2b, what is (3 ⊙ 4) ⊙ 2?

First: 3 ⊙ 4 = 3 + 2(4) = 11. Then: 11 ⊙ 2 = 11 + 2(2) = 15. Therefore, the answer is 15.

18. If a □ b = 2a − b + 3, find 5 □ 4.

5 □ 4 = 2(5) − 4 + 3 = 10 − 4 + 3 = 9.

19. Which expression is equal to 4(7 + 2) − 5?

Using the distributive property: 4(7 + 2) = 4 × 7 + 4 × 2. Therefore, the equivalent expression is 4 × 7 + 4 × 2 − 5.

20. If a ★ b = (a + b) / 2, what is 8 ★ 14?

8 ★ 14 = (8 + 14) / 2 = 22 / 2 = 11.

21. If a ◇ b = a(b + 1), what is 4 ◇ 5?

4 ◇ 5 = 4(5 + 1) = 4 × 6 = 24.

22. Calculate: 72 ÷ 8 × 3 − 4

Division and multiplication are performed from left to right: 72 ÷ 8 = 9, 9 × 3 = 27, and 27 − 4 = 23.

23. If x ⊙ y = x + y − xy, what is 2 ⊙ 3?

2 ⊙ 3 = 2 + 3 − (2 × 3) = 5 − 6 = −1.

24. If a ★ b = 2a + b, which value of b makes 5 ★ b = 17?

5 ★ b = 2(5) + b = 10 + b. Therefore: 10 + b = 17, so b = 7.

25. If a △ b = (a − b)² + 1, what is 6 △ 2?

6 △ 2 = (6 − 2)² + 1 = 4² + 1 = 16 + 1 = 17.
