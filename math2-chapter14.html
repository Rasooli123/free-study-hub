MATHEMATICS 2

Matrices

Chapter 14 · 25 Questions

1. A matrix has 2 rows and 3 columns. What is its order?

Matrix order is written rows × columns, so it is 2 × 3.

2. In A = [[1, 2], [3, 4]], what is a₁₂?

a₁₂ is the entry in row 1, column 2, which is 2.

3. Find [[1, 2], [3, 4]] + [[2, 0], [−1, 5]].

Add corresponding entries: [[1+2, 2+0], [3−1, 4+5]] = [[3, 2], [2, 9]].

4. Find [[5, 1], [2, 4]] − [[1, 3], [−2, 1]].

Subtract corresponding entries: [[5−1, 1−3], [2−(−2), 4−1]] = [[4, −2], [4, 3]].

5. Find 3[[1, −2], [0, 4]].

Multiply every entry by 3.

6. If I is the 2 × 2 identity matrix, what is AI?

Multiplying a matrix by the compatible identity matrix leaves it unchanged.

7. Find AB where A = [[1, 2], [0, 1]] and B = [[3, 1], [2, 4]].

AB = [[1·3+2·2, 1·1+2·4], [0·3+1·2, 0·1+1·4]] = [[7, 9], [2, 4]].

8. What is det[[a, b], [c, d]]?

The determinant of a 2 × 2 matrix is ad − bc.

9. Find det[[2, 3], [1, 4]].

det = 2·4 − 3·1 = 8 − 3 = 5.

10. When does a 2 × 2 matrix have an inverse?

A square matrix is invertible exactly when its determinant is not zero.

11. What is the transpose of [[1, 2, 3], [4, 5, 6]]?

The transpose switches rows and columns.

12. Which matrix is the 2 × 2 identity matrix?

The identity has 1s on the main diagonal and 0s elsewhere.

13. Find det[[5, 0], [0, −2]].

The determinant is 5(−2) − 0·0 = −10.

14. For same-sized matrices A and B, which statement is always true?

Matrix addition is commutative, so A + B = B + A.

15. Which statement about matrix multiplication is generally true?

Matrix multiplication is generally not commutative; AB and BA may differ.

16. What is the determinant of the identity matrix I₂?

det[[1, 0], [0, 1]] = 1·1 − 0·0 = 1.

17. Solve 2x + y = 5 and x − y = 1.

From x − y = 1, x = y + 1. Then 2(y + 1) + y = 5 gives y = 1 and x = 2.

18. Is A = [[1, 0], [0, 0]] singular?

Its determinant is 1·0 − 0·0 = 0. A matrix with zero determinant is singular.

19. Find [1, 2] [[3], [4]].

Row-by-column multiplication gives 1·3 + 2·4 = 11.

20. When can two matrices be added?

Addition requires a matching entry in every position, so the matrices must have the same order.

21. If A is 3 × 2 and B is 2 × 4, what is the order of AB?

The inner dimensions 2 match; the product takes the outer dimensions, 3 × 4.

22. What is the trace of [[2, 1], [5, 3]]?

The trace is the sum of main-diagonal entries: 2 + 3 = 5.

23. Find det[[1, 2], [2, 4]].

det = 1·4 − 2·2 = 0.

24. What is the inverse of [[2, 0], [0, 3]]?

The inverse of a nonzero diagonal matrix has reciprocal diagonal entries.

25. Find A² for A = [[0, 1], [−1, 0]].

Multiplying A by itself gives [[−1, 0], [0, −1]] = −I.
