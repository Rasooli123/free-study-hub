MATHEMATICS 2

Polynomials

Chapter 1 · 25 Questions

1. What is the degree of the polynomial 5x⁴ − 3x² + 7?

The degree of a polynomial is the highest exponent of the variable. The highest exponent here is 4, so the degree is 4.

2. What is the leading coefficient of 7x³ − 4x + 9?

The leading coefficient is the coefficient of the term with the highest degree. The highest-degree term is 7x³, so the leading coefficient is 7.

3. What is the value of P(2) if P(x) = x² + 3x − 4?

Substitute x = 2: P(2) = 2² + 3(2) − 4 = 4 + 6 − 4 = 6.

4. Simplify: (3x² + 5x − 2) + (2x² − 3x + 6)

Combine like terms: 3x² + 2x² = 5x², 5x − 3x = 2x, and −2 + 6 = 4. Therefore, the result is 5x² + 2x + 4.

5. Simplify: (4x² + 7x − 3) − (x² + 2x − 5)

Distribute the minus sign: 4x² + 7x − 3 − x² − 2x + 5. Combining like terms gives: 3x² + 5x + 2.

6. Expand: (x + 3)(x + 2)

Multiply each term: x(x + 2) + 3(x + 2) = x² + 2x + 3x + 6 = x² + 5x + 6.

7. Which identity is correct?

The standard algebraic identity is: (a + b)² = a² + 2ab + b².

8. Factorize: x² + 7x + 12

We need two numbers whose product is 12 and whose sum is 7. They are 3 and 4. Therefore: x² + 7x + 12 = (x + 3)(x + 4).

9. Factorize: x² − 9

This is a difference of squares: a² − b² = (a − b)(a + b). Therefore: x² − 9 = x² − 3² = (x − 3)(x + 3).

10. If P(x) = x³ − 2x² + x − 5, what is P(1)?

Substitute x = 1: P(1) = 1³ − 2(1²) + 1 − 5 = 1 − 2 + 1 − 5 = −5.

11. What is the remainder when P(x) = x² + 3x + 5 is divided by x − 2?

By the remainder theorem, when dividing by x − a, the remainder is P(a). Here a = 2: P(2) = 2² + 3(2) + 5 = 4 + 6 + 5 = 15.

12. If x − 3 is a factor of P(x) = x² + kx − 6, find k.

If x − 3 is a factor, then P(3) = 0. Therefore: 3² + 3k − 6 = 0 → 9 + 3k − 6 = 0 → 3 + 3k = 0 → k = −1.

13. Which of the following is a polynomial?

A polynomial has non-negative integer exponents of the variable. Therefore, 3x² − 5x + 2 is a polynomial.

14. Expand: (2x − 3)²

Using (a − b)² = a² − 2ab + b²: (2x − 3)² = 4x² − 12x + 9.

15. Factorize: 3x² + 6x

The greatest common factor is 3x. Therefore: 3x² + 6x = 3x(x + 2).

16. If P(x) = 2x³ − x + 4, what is P(−1)?

Substitute x = −1: P(−1) = 2(−1)³ − (−1) + 4 = −2 + 1 + 4 = 3.

17. Which is the factorization of x² − 5x + 6?

We need two numbers whose product is 6 and whose sum is −5. They are −2 and −3. Therefore: x² − 5x + 6 = (x − 2)(x − 3).

18. If P(x) = x³ − 4x, which value is a root of P(x)?

Factorize: P(x) = x³ − 4x = x(x² − 4) = x(x − 2)(x + 2). Therefore, x = 2 is a root.

19. What is the remainder when x³ + 2x² − x + 4 is divided by x + 1?

Since the divisor is x + 1 = x − (−1), use P(−1): P(−1) = (−1)³ + 2(−1)² − (−1) + 4 = −1 + 2 + 1 + 4 = 6.

20. Simplify: (x + 4)² − x²

Expand: (x + 4)² = x² + 8x + 16. Therefore: x² + 8x + 16 − x² = 8x + 16.

21. If x = 2 is a root of x² + kx − 8 = 0, find k.

Since x = 2 is a root, substitute x = 2: 2² + 2k − 8 = 0 → 4 + 2k − 8 = 0 → 2k − 4 = 0 → 2k = 4 → k = 2.

22. Which value of x satisfies x² − 7x + 12 = 0?

Factorize: x² − 7x + 12 = (x − 3)(x − 4). Therefore, the roots are 3 and 4. Among the choices, x = 3.

23. What is the coefficient of x² in 4x³ − 7x² + 2x − 9?

The x² term is −7x². Therefore, its coefficient is −7.

24. If P(x) = x² − 4x + 7, what is P(3)?

Substitute x = 3: P(3) = 3² − 4(3) + 7 = 9 − 12 + 7 = 4.

25. If P(x) = x² − 5x + 6, what is P(2)?

Substitute x = 2: P(2) = 2² − 5(2) + 6 = 4 − 10 + 6 = 0. Therefore, x = 2 is a root of the polynomial.
