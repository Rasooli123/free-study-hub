Chapter 1: Şifreler

Practice coding, symbols, sequences and password patterns.

1. In a certain code, each number is multiplied by 2 and then 3 is added. If 7 is coded as 17, how is 12 coded?

The rule is ×2 + 3. Therefore, 12 × 2 + 3 = 27.

2. In a code, A = 1, B = 2, C = 3, ..., Z = 26. What is the code of BAD?

B = 2, A = 1 and D = 4. Therefore, BAD → 214.

3. Observe the coded pairs:

12 → 21
34 → 43
56 → 65

Using the same rule, how is 78 coded?

The two digits are reversed. Therefore, 78 → 87.

4. A code follows this pattern:

2 → 7    4 → 13    6 → 19

What is the code for 8?

The rule is ×3 + 1. Therefore, 8 × 3 + 1 = 25.

5. A number is coded by first adding 4 and then multiplying the result by 3. What is the code of 5?

First: 5 + 4 = 9. Then: 9 × 3 = 27.

6. The symbols have the following values:

▲ = 6    ● = 4    ■ = 9

What is ▲ + ■ − ●?

6 + 9 − 4 = 11.

7. If A = 3, B = 6, C = 9 and D = 12, what is the code of CAD?

C = 9, A = 3 and D = 12. Therefore, CAD → 9312.

8. Observe the pattern:

3 → 8    5 → 12    7 → 16

What is the code for 10?

The rule is ×2 + 2. Therefore, 10 × 2 + 2 = 22.

9. Each letter is replaced by the letter immediately after it in the alphabet. How is CAT coded?

C → D, A → B and T → U. Therefore, CAT → DBU.

10. Each letter is replaced by the letter immediately before it. How is GAME coded?

G → F, A → Z, M → L and E → D. Therefore, GAME → FZLD.

11. Observe the symbol sequence:

▲   ●   ■   ▲   ●   ?

Which symbol should replace the question mark?

The pattern ▲, ●, ■ repeats. Therefore, the missing symbol is ■.

12. If ▲ = 5 and ● = 7, and ▲● means the product of their values, what is ▲●?

▲● = 5 × 7 = 35.

13. A three-digit number is coded by increasing its first digit by 2, decreasing its second digit by 1, and leaving the third digit unchanged. What is the code of 473?

4 + 2 = 6, 7 − 1 = 6, and 3 stays unchanged. Therefore, 473 → 663.

14. If 246 is coded as 642, 135 as 531 and 472 as 274, what rule is being used?

In every example, the entire number is written in reverse order.

15. A code is obtained by adding the first two digits and multiplying their sum by the third digit. What is the code of 234?

(2 + 3) × 4 = 5 × 4 = 20.

16. Observe the coded pairs:

AB → 12
BC → 23
CD → 34

Using the same rule, what is DE?

D = 4 and E = 5. Therefore, DE → 45.

17. The symbols have the following values:

◆ = 8    ● = 5    ▲ = 3

What is ◆ − ▲ + ●?

8 − 3 + 5 = 10.

18. The triangle moves one position to the right in each row:

▲ ○ ○ ○
○ ▲ ○ ○
○ ○ ▲ ○
?

Which arrangement comes next?

The triangle moves one position to the right each time. Therefore, the answer is ○ ○ ○ ▲.

19. The alphabet positions of the letters are written in reverse order. What is the code of DOG?

D = 4, O = 15 and G = 7. Reversing the order gives 7, 15, 4 → 7154.

20. A number is coded in three steps: add 2, multiply by 3, then subtract 1. What is the code of 5?

5 + 2 = 7 → 7 × 3 = 21 → 21 − 1 = 20.

21. Which figure should come next?

▲ → ▶ → ▼ → ◀ → ?

The triangle rotates 90° clockwise at each step. After ◀ comes ▲.

22. In a code system, vowels are replaced by 0 and consonants by 1. What is the code of CAT?

C is a consonant → 1, A is a vowel → 0, T is a consonant → 1. Therefore, CAT → 101.

23. In a code, odd digits are increased by 2 while even digits are decreased by 1. What is the code of 538?

5 → 7, 3 → 5 and 8 → 7. Therefore, 538 → 757.

24. A password contains three digits. The first digit is twice the second digit, while the third digit is 2 more than the second digit. If the second digit is 3, what is the password?

The first digit is 2 × 3 = 6. The second is 3. The third is 3 + 2 = 5. Therefore, the password is 635.

25. A code follows three rules in order:

1. Reverse the digits.

2. Add 1 to the first digit.

3. Subtract 1 from the last digit.

What is the final code of 352?

First, reverse 352 → 253. Add 1 to the first digit: 253 → 353. Then subtract 1 from the last digit: 353 → 352. Therefore, the final code is 352.
