Chapter 11: Sets

25 TR-YÖS Practice Questions

1. If A = {1, 2, 3, 4, 5}, how many elements does A contain?

The elements of A are 1, 2, 3, 4 and 5. Therefore, A contains 5 elements.

2. Which of the following is a subset of A = {2, 4, 6, 8}?

A subset can contain only elements that belong to A. Both 2 and 6 belong to A, so {2, 6} is a subset.

3. Let A = {1, 2, 3} and B = {3, 4, 5}. What is A ∪ B?

The union contains every element that belongs to either set. Therefore, A ∪ B = {1, 2, 3, 4, 5}.

4. Let A = {1, 2, 3, 4} and B = {3, 4, 5, 6}. What is A ∩ B?

The intersection contains the elements common to both sets. The common elements are 3 and 4. Therefore, A ∩ B = {3, 4}.

5. If A = {1, 2, 3, 4, 5} and B = {2, 4}, what is A − B?

A − B contains the elements of A that are not in B. Removing 2 and 4 from A leaves {1, 3, 5}.

6. If A has 6 elements, how many subsets does A have?

A set with n elements has 2ⁿ subsets. Therefore, a set with 6 elements has 2⁶ = 64 subsets.

7. If A = {a, b, c}, which of the following is NOT a subset of A?

Every element of a subset must belong to A. Since d does not belong to A, {b, d} is not a subset.

8. If A = {1, 2, 3} and B = {3, 4, 5}, how many elements are in A ∪ B?

A ∪ B = {1, 2, 3, 4, 5}. The element 3 appears in both sets but is counted only once. Therefore, there are 5 elements.

9. If |A| = 8, |B| = 7 and |A ∩ B| = 3, what is |A ∪ B|?

Use: |A ∪ B| = |A| + |B| − |A ∩ B|. Therefore, 8 + 7 − 3 = 12.

10. If A and B are disjoint sets, which statement is true?

Disjoint sets have no common elements. Therefore, their intersection is the empty set: A ∩ B = ∅.

11. Let U = {1, 2, 3, 4, 5, 6} and A = {2, 4, 6}. What is Aᶜ?

The complement of A contains the elements of the universal set U that are not in A. Therefore, Aᶜ = {1, 3, 5}.

12. If A ⊂ B and B has 7 elements, which of the following could be the number of elements of A?

Since A is a proper subset of B, A must contain fewer elements than B. Therefore, 5 is possible.

13. If A = {1, 2, 3, 4} and B = {2, 4, 6}, what is A ∩ B?

The elements common to both A and B are 2 and 4. Therefore, A ∩ B = {2, 4}.

14. If |A| = 10, |B| = 12 and |A ∪ B| = 18, what is |A ∩ B|?

Using |A ∪ B| = |A| + |B| − |A ∩ B|, we get: 18 = 10 + 12 − |A ∩ B|. Therefore, |A ∩ B| = 4.

15. If A = {1, 2, 3} and B = {3, 4, 5}, what is B − A?

B − A contains elements that belong to B but not A. Since 3 belongs to both sets, it is removed. Therefore, B − A = {4, 5}.

16. A set has 4 elements. How many proper subsets does it have?

A set with 4 elements has 2⁴ = 16 subsets. One of them is the set itself, which is not a proper subset. Therefore, the number of proper subsets is 16 − 1 = 15.

17. In a group of 40 students, 24 study Mathematics, 18 study Physics, and 10 study both. How many students study at least one of the two subjects?

Students studying at least one subject are: 24 + 18 − 10 = 32. We subtract the 10 students who were counted twice.

18. In a class of 50 students, 30 like football, 25 like basketball, and 12 like both. How many like neither sport?

Students who like at least one sport: 30 + 25 − 12 = 43. Therefore, students who like neither: 50 − 43 = 7.

19. If A and B are sets such that A ∩ B = A, which statement must be true?

If A ∩ B = A, every element of A must also belong to B. Therefore, A is a subset of B: A ⊆ B.

20. If A ∪ B = A, which statement must be true?

If A ∪ B = A, every element of B must already be contained in A. Therefore, B ⊆ A.

21. Let U contain 30 elements. If A contains 18 elements, how many elements are in Aᶜ?

The complement contains all elements of U that are not in A. Therefore, |Aᶜ| = 30 − 18 = 12.

22. If |A| = 15, |B| = 12 and |A ∩ B| = 5, how many elements are in A but not in B?

A contains 15 elements, including the 5 elements shared with B. Therefore, elements only in A: 15 − 5 = 10.

23. If A has 5 elements and B has 4 elements, what is the maximum possible number of elements in A ∪ B?

The union is largest when the sets have no common elements. Therefore: 5 + 4 = 9.

24. If A has 8 elements and B has 6 elements, what is the minimum possible number of elements in A ∪ B?

To make the union as small as possible, every element of the smaller set B should be contained in A. Therefore, the union has 8 elements.

25. In a group of 60 students, 35 study Mathematics, 28 study Physics, and 15 study both. How many students study neither Mathematics nor Physics?

Students studying at least one subject: 35 + 28 − 15 = 48. Therefore, students studying neither: 60 − 48 = 12.
