MATHEMATICS 2

Logarithms

Chapter 7 · 25 Questions

1. What is log₂ 8?

Because 2³ = 8, log₂ 8 = 3.

2. What is log₁₀ 1000?

10³ = 1000, so log₁₀ 1000 = 3.

3. What is log₃ 1?

Any nonzero base raised to the power 0 equals 1.

4. What is log₅ 25?

5² = 25, so log₅ 25 = 2.

5. What is log₂(1/8)?

Since 1/8 = 2⁻³, the logarithm is −3.

6. If log₂ x = 5, what is x?

log₂ x = 5 means x = 2⁵ = 32.

7. What is log₁₀ 0.01?

0.01 = 10⁻², so log₁₀ 0.01 = −2.

8. What is log₃ 81?

3⁴ = 81, so log₃ 81 = 4.

9. For a > 0 and a ≠ 1, what is logₐ(a⁷)?

A logarithm and its matching exponential base undo each other: logₐ(a⁷) = 7.

10. What is log₂ 16 + log₂ 2?

log₂ 16 = 4 and log₂ 2 = 1, so the sum is 5.

11. What is log₃ 27 − log₃ 3?

log₃ 27 = 3 and log₃ 3 = 1, giving 2.

12. What is log₁₀ 2 + log₁₀ 5?

log₁₀ 2 + log₁₀ 5 = log₁₀(10) = 1.

13. What is log₂ 12 − log₂ 3?

Use the quotient rule: log₂(12/3) = log₂ 4 = 2.

14. If log₅ x = 2, what is x?

x = 5² = 25.

15. What is log₄ 64?

4³ = 64, so log₄ 64 = 3.

16. What is log₉ 3?

9¹ᐟ² = 3, so log₉ 3 = 1/2.

17. Solve log₂(x − 1) = 3.

x − 1 = 2³ = 8, so x = 9.

18. Solve log₃(x + 1) = 2.

x + 1 = 3² = 9, hence x = 8.

19. If log₁₀ x = −1, what is x?

x = 10⁻¹ = 0.1.

20. Solve log₂ x + log₂(x − 2) = 3.

Combine logs: log₂[x(x − 2)] = 3, so x² − 2x = 8. Roots are 4 and −2, but x must exceed 2; therefore x = 4.

21. What is log₅ 125?

5³ = 125, so the value is 3.

22. If logₐ b = 2, which statement is true?

logₐ b = 2 is equivalent to a² = b.

23. Between which consecutive integers is log₂ 7?

2² = 4 and 2³ = 8. Since 4 < 7 < 8, 2 < log₂ 7 < 3.

24. What is ln(e⁴)?

The natural logarithm is base e, so ln(e⁴) = 4.

25. Solve log₃ x = log₃ 12.

Equal logarithms with the same valid base have equal arguments, so x = 12.
