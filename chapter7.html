Chapter 7: Simple Inequalities & Absolute Value

Practice questions based on the chapter.

1. Solve: 3x + 5 > 17

Subtract 5 from both sides: 3x > 12. Dividing by 3 gives x > 4.

2. Solve: 5 − 2x ≤ 11

Subtract 5: −2x ≤ 6. Dividing by −2 reverses the inequality: x ≥ −3.

3. Which value satisfies 2x − 7 < 9?

2x − 7 < 9 gives 2x < 16, so x < 8. Among the choices, only 7 satisfies the inequality.

4. Solve: −4x > 20

Dividing both sides by −4 reverses the inequality. Therefore, x < −5.

5. Solve: 2 < x + 3 ≤ 8

Subtract 3 from all three parts: 2 − 3 < x ≤ 8 − 3. Therefore, −1 < x ≤ 5.

6. If 3x − 4 ≥ 2x + 5, what is the smallest integer x?

Subtract 2x: x − 4 ≥ 5. Therefore x ≥ 9. The smallest integer is 9.

7. What is the solution of |x| = 6?

The absolute value of a number represents its distance from zero. Both 6 and −6 have absolute value 6.

8. Solve: |x| < 4

|x| < 4 means that the distance of x from zero is less than 4. Therefore, −4 < x < 4.

9. Solve: |x| ≤ 7

|x| ≤ 7 means x is at a distance of at most 7 from zero. Thus, −7 ≤ x ≤ 7.

10. Solve: |x| > 5

|x| > 5 means x is more than 5 units away from zero. Therefore, x < −5 or x > 5.

11. Solve: |2x| = 10

|2x| = 10 means 2x = 10 or 2x = −10. Thus, x = 5 or x = −5.

12. Solve: |x − 3| = 4

x − 3 = 4 gives x = 7. x − 3 = −4 gives x = −1. Therefore, x = −1 or x = 7.

13. Solve: |x + 2| = 7

x + 2 = 7 gives x = 5. x + 2 = −7 gives x = −9. Therefore, x = 5 or x = −9.

14. Solve: |x − 1| < 3

|x − 1| < 3 means: −3 < x − 1 < 3. Adding 1 throughout gives: −2 < x < 4.

15. Solve: |2x − 1| ≤ 5

−5 ≤ 2x − 1 ≤ 5. Add 1: −4 ≤ 2x ≤ 6. Divide by 2: −2 ≤ x ≤ 3.

16. Which value does NOT satisfy |x − 2| ≤ 4?

|x − 2| ≤ 4 means −2 ≤ x ≤ 6. The value 7 is outside this interval, so it does not satisfy the inequality.

17. If |x + 4| = 0, what is x?

An absolute value equals zero only when the expression inside it is zero. Therefore: x + 4 = 0, so x = −4.

18. If −3x + 7 < 16, which statement is true?

−3x + 7 < 16 gives −3x < 9. Dividing by −3 reverses the inequality: x > −3.

19. Solve: 4(x − 2) ≥ 2x + 6

Expand: 4x − 8 ≥ 2x + 6. Subtract 2x: 2x − 8 ≥ 6. Add 8: 2x ≥ 14. Therefore, x ≥ 7.

20. Solve: 7 − 3x ≤ 2x − 8

7 − 3x ≤ 2x − 8. Add 3x: 7 ≤ 5x − 8. Add 8: 15 ≤ 5x. Therefore, x ≥ 3.

21. How many integer solutions satisfy |x| < 4?

|x| < 4 means −4 < x < 4. The integer solutions are: −3, −2, −1, 0, 1, 2, 3. There are 7 integers.

22. How many integers satisfy |x − 2| ≤ 3?

|x − 2| ≤ 3 means: −3 ≤ x − 2 ≤ 3. Adding 2 gives: −1 ≤ x ≤ 5. The integers are −1, 0, 1, 2, 3, 4, 5, giving 7 solutions.

23. If 2 < 3x − 1 ≤ 11, what is the range of x?

Start with: 2 < 3x − 1 ≤ 11. Add 1: 3 < 3x ≤ 12. Divide by 3: 1 < x ≤ 4.

24. Which inequality is equivalent to |x + 1| ≥ 4?

For |A| ≥ k, the expression A must be at least k units from zero in either direction. Therefore: x + 1 ≤ −4 or x + 1 ≥ 4.

25. If |2x − 3| < 7, which interval contains all possible values of x?

−7 < 2x − 3 < 7. Add 3: −4 < 2x < 10. Divide by 2: −2 < x < 5.
