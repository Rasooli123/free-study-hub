MATHEMATICS 2

Trigonometry

Chapter 5 · 25 Questions

1. What is sin 30°?

In the 30°–60°–90° triangle, sin 30° = 1/2.

2. What is cos 60°?

The standard value is cos 60° = 1/2.

3. What is tan 45°?

In a 45°–45°–90° triangle, opposite and adjacent sides are equal, so tan 45° = 1.

4. What is sin 90°?

The sine of 90° is 1.

5. What is cos 180°?

On the unit circle, the point at 180° has x-coordinate −1, so cos 180° = −1.

6. What is tan 0°?

tan θ = sin θ/cos θ. At 0°, this is 0/1 = 0.

7. What is sin²θ + cos²θ?

The Pythagorean identity is sin²θ + cos²θ = 1.

8. In a right triangle, the side opposite θ is 3 and the hypotenuse is 5. What is sin θ?

sin θ is opposite/hypotenuse = 3/5.

9. In a right triangle, the side adjacent to θ is 8 and the hypotenuse is 10. What is cos θ?

cos θ is adjacent/hypotenuse = 8/10 = 4/5.

10. Convert 150° to radians.

Multiply 150 by π/180: 150π/180 = 5π/6.

11. Convert π/3 radians to degrees.

π radians equals 180°, so π/3 equals 60°.

12. If sin θ = 3/5 and θ is acute, what is cos θ?

Using a 3–4–5 triangle, the adjacent side is 4, so cos θ = 4/5.

13. If cos θ = 5/13 and θ is acute, what is tan θ?

The opposite side is √(13² − 5²) = 12. Thus tan θ = 12/5.

14. If tan θ = √3 and θ is acute, what is θ?

The standard value tan 60° is √3.

15. sin(90° − θ) equals which expression?

The cofunction identity is sin(90° − θ) = cos θ.

16. For acute θ, what is cos(180° − θ)?

The angle 180° − θ lies in Quadrant II, where cosine is negative: cos(180° − θ) = −cos θ.

17. What is cos 30°?

The standard value is cos 30° = √3/2.

18. In 0° ≤ x ≤ 360°, when is sin x = 1?

Sine reaches 1 at the top of the unit circle, x = 90°.

19. In 0° ≤ x < 360°, which values satisfy tan x = 0?

Tangent is zero where sine is zero and cosine is nonzero: 0° and 180°.

20. In 0° ≤ x < 360°, which values satisfy cos x = 0?

Cosine is zero on the y-axis, at 90° and 270°.

21. In 0° ≤ x < 360°, which values satisfy sin x = 1/2?

The reference angle is 30°, and sine is positive in Quadrants I and II.

22. What is tan 30°?

tan 30° = 1/√3 = √3/3.

23. In a right triangle, the side opposite θ is 5 and the adjacent side is 12. What is tan θ?

tan θ is opposite/adjacent = 5/12.

24. What is sin 45°?

The standard value is sin 45° = √2/2.

25. If sec θ = 2, what is cos θ?

sec θ = 1/cos θ. Thus cos θ = 1/2.
