Chapter 3: First-Degree Equations

Practice questions based on the chapter.

1. Solve for x: 3x + 7 = 25

3x + 7 = 25 → 3x = 18 → x = 6.

2. Solve: 5x - 9 = 2x + 12

5x − 2x = 12 + 9 → 3x = 21 → x = 7.

3. If 4(x - 3) = 2x + 10, what is x?

4x − 12 = 2x + 10 → 2x = 22 → x = 11.

4. Solve: 7 - 2(x + 3) = -9

7 − 2x − 6 = −9 → 1 − 2x = −9 → −2x = −10 → x = 5.

5. Solve: (x + 4)/3 = 6

x + 4 = 18 → x = 14.

6. Solve: (2x - 3)/5 = (x + 4)/2

Multiply by 10: 2(2x − 3) = 5(x + 4). Thus 4x − 6 = 5x + 20 → x = −26.

7. If 3(2x - 5) - 4(x + 1) = 9, what is x?

6x − 15 − 4x − 4 = 9 → 2x − 19 = 9 → 2x = 28 → x = 14.

8. Solve: 0.4x + 3.2 = 8

0.4x = 4.8 → x = 12.

9. Solve: 5(x - 2) = 3(x + 4) + 6

5x − 10 = 3x + 12 + 6 → 2x = 28 → x = 14.

10. If 2x + 5 = 17, what is the value of 3x - 1?

2x = 12 → x = 6. Therefore, 3x − 1 = 18 − 1 = 17.

11. Solve: 4 - 3(2x - 1) = 2x + 11

4 − 6x + 3 = 2x + 11 → 7 − 6x = 2x + 11 → −4 = 8x → x = −1/2.

12. Solve: 2(x - 3) + 5 = 3(x - 1) - 4

2x − 6 + 5 = 3x − 3 − 4 → 2x − 1 = 3x − 7 → x = 6.

13. If 5x - 2 = 3x + 10, find x/2.

5x − 3x = 10 + 2 → 2x = 12 → x = 6. Therefore x/2 = 3.

14. For what value of k does the equation (k - 2)x = 12 have no solution?

If k = 2, the equation becomes 0x = 12, which is impossible. Therefore k = 2.

15. For what value of k does (k - 3)x = 0 have infinitely many solutions?

When k = 3, the equation becomes 0x = 0, which is true for every x. Thus there are infinitely many solutions.

16. Solve: (3x + 2)/4 - (x - 1)/2 = 5

Multiply by 4: 3x + 2 − 2(x − 1) = 20 → 3x + 2 − 2x + 2 = 20 → x + 4 = 20 → x = 16.

17. If 3x - 4 = 2(x + 5), what is x + 3?

3x − 4 = 2x + 10 → x = 14. Therefore x + 3 = 17.

18. A number increased by 7 is equal to twice the number minus 5. What is the number?

Let the number be x. x + 7 = 2x − 5 → x = 12.

19. Three consecutive integers have a sum of 72. What is the middle integer?

Let the middle integer be x. Then (x − 1) + x + (x + 1) = 72 → 3x = 72 → x = 24.

20. The sum of two numbers is 41. The larger number is 5 more than twice the smaller number. What is the smaller number?

Let the smaller number be x. The larger is 2x + 5. Thus x + 2x + 5 = 41 → 3x = 36 → x = 12.

21. Solve: 2[3x - (x - 4)] = 20

2[3x − x + 4] = 20 → 2(2x + 4) = 20 → 4x + 8 = 20 → x = 3.

22. If 4(x + 2) - 3(x - 1) = 19, what is 2x?

4x + 8 − 3x + 3 = 19 → x + 11 = 19 → x = 8. Therefore 2x = 16.

23. Solve: 0.3(10x - 5) = 0.5(4x + 3)

3x − 1.5 = 2x + 1.5 → x = 3.

24. If 2x + 3 = 5x - 12, what is the value of x²?

2x + 3 = 5x − 12 → 15 = 3x → x = 5. Therefore x² = 25.

25. If (x - 2)/3 + (x + 1)/2 = 9, what is x?

Multiply by 6: 2(x − 2) + 3(x + 1) = 54 → 5x − 1 = 54 → 5x = 55 → x = 11.
