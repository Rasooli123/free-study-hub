MATHEMATICS 2

Special-Defined Functions

Chapter 9 · 25 Questions

1. If f(x) = |x − 3|, find f(1).

f(1) = |1 − 3| = |−2| = 2.

2. If [x] denotes the greatest integer less than or equal to x, what is [3.7]?

The greatest integer not greater than 3.7 is 3.

3. What is the least integer greater than or equal to −2.3?

The least integer that is at least −2.3 is −2.

4. What is [−1.2], where [x] is the greatest-integer function?

The largest integer not greater than −1.2 is −2.

5. What is sgn(−5)?

The sign function returns −1 for a negative input.

6. Let f(x) = x² for x ≥ 0 and f(x) = −x for x < 0. Find f(−3).

Since −3 < 0, use f(x) = −x. Thus f(−3) = 3.

7. What is the domain of g(x) = 1/x?

Division by zero is undefined, so x cannot be 0.

8. If h(x) = |2x + 1|, find h(−2).

h(−2) = |−4 + 1| = |−3| = 3.

9. What is [5]?

Since 5 is already an integer, its greatest integer is itself.

10. What is ⌈4.01⌉, the least integer greater than or equal to 4.01?

The next integer at or above 4.01 is 5.

11. What is |7 − 2|?

|7 − 2| = |5| = 5.

12. Let f(x) = x + 1 for x < 0 and f(x) = x² for x ≥ 0. Find f(0).

0 satisfies x ≥ 0, so use x². Therefore f(0) = 0.

13. What is [2.4] + ⌈2.4⌉?

[2.4] = 2 and ⌈2.4⌉ = 3, so their sum is 5.

14. What is [−3.0]?

The value is an integer, so the greatest-integer function returns −3.

15. What is ⌈−4⌉?

The least integer greater than or equal to the integer −4 is −4 itself.

16. Solve |x| = 5.

Both 5 and −5 have absolute value 5.

17. What is sgn(0)?

The sign function is 0 at x = 0.

18. Let f(x) = 2x + 1 for x ≤ 1 and f(x) = x² for x > 1. Find f(1).

Since 1 is included in x ≤ 1, use 2x + 1. This gives 2(1) + 1 = 3.

19. If f(x) = |x|, what is f(−a)?

f(−a) = |−a| = |a|.

20. Which interval solves [x] = 2?

The greatest integer is 2 exactly when x is at least 2 and less than 3.

21. Which interval solves ⌈x⌉ = 2?

The least integer at or above x equals 2 when 1 < x ≤ 2.

22. Solve |x − 4| = 1.

x − 4 = ±1, giving x = 3 or x = 5.

23. What is [2.999]?

2.999 is less than 3, so its greatest integer is 2.

24. Let f(x) = x + 2 for x < 2 and f(x) = 2x − 1 for x ≥ 2. Find f(2).

At x = 2 use 2x − 1, which gives 4 − 1 = 3.

25. Solve |x + 1| = 0.

An absolute value is zero only when its inside is zero: x + 1 = 0.
