MATHEMATICS 1

Cartesian Product, Relations & Functions

Chapter 12 · 25 Questions

1. If A = {1, 2, 3} and B = {a, b}, how many elements does A × B contain?

The number of ordered pairs in A × B is |A| × |B| = 3 × 2 = 6.

2. If A = {1, 2} and B = {3, 4}, which of the following belongs to A × B?

In A × B, the first element must come from A and the second element must come from B. Therefore, (1, 4) belongs to A × B.

3. If A = {2, 4} and B = {1, 3}, which statement is true?

The first element must belong to A and the second must belong to B. Since 2 ∈ A and 3 ∈ B, (2, 3) belongs to A × B.

4. If A = {1, 2} and B = {a, b, c}, what is |A × B|?

|A × B| = |A| × |B| = 2 × 3 = 6.

5. If A = {1, 2, 3}, which of the following is NOT in A × A?

Both coordinates must belong to A. Since 4 is not in A, (3, 4) is not in A × A.

6. If |A| = 4 and |B| = 5, how many ordered pairs are in A × B?

|A × B| = |A| × |B| = 4 × 5 = 20.

7. Let A = {1, 2} and B = {3, 4}. Which statement is correct?

Ordered pairs depend on order. For example, (1, 3) is in A × B, while (1, 3) is not in B × A. Therefore, A × B ≠ B × A.

8. Let A = {1, 2, 3} and B = {2, 4}. Which ordered pair is in B × A?

In B × A, the first element must come from B and the second from A. Since 4 ∈ B and 3 ∈ A, (4, 3) is correct.

9. A relation R from A to B is a subset of which set?

A relation from A to B is a set of ordered pairs selected from A × B. Therefore, R ⊆ A × B.

10. Let A = {1, 2, 3} and B = {4, 5}. Which could be a relation from A to B?

A relation from A to B contains ordered pairs whose first element is from A and second element is from B. Therefore, {(1, 4), (2, 5)} is a valid relation.

11. Let R = {(1, 4), (2, 5), (3, 5)}. What is the domain of R?

The domain consists of the first elements of the ordered pairs. Therefore, the domain is {1, 2, 3}.

12. For R = {(1, 4), (2, 5), (3, 5)}, what is the range of R?

The range consists of the second elements of the ordered pairs. The second elements are 4 and 5, so the range is {4, 5}.

13. Which relation is a function from A = {1, 2, 3} to B = {4, 5}?

A function assigns exactly one output to every input. In A), each of 1, 2, and 3 appears exactly once as a first element.

14. Which relation is NOT a function?

In C), the input 1 has two different outputs: 3 and 4. Therefore, this relation is not a function.

15. If f(x) = 2x + 3, what is f(4)?

Substitute x = 4: f(4) = 2(4) + 3 = 8 + 3 = 11.

16. If f(x) = 3x − 2 and f(x) = 13, what is x?

3x − 2 = 13. Therefore, 3x = 15 and x = 5.

17. If f(x) = x2 − 1, what is f(3)?

f(3) = 32 − 1 = 9 − 1 = 8.

18. If f(x) = 5 − 2x, for which value of x is f(x) = 11?

5 − 2x = 11. Thus, −2x = 6, so x = −3.

19. Let f(x) = x + 4. If f(a) = 10, what is a?

f(a) = a + 4 = 10. Therefore, a = 6.

20. A function has the values f(1) = 3, f(2) = 5, and f(3) = 7. Which ordered pair belongs to its graph?

Since f(2) = 5, the ordered pair (2, 5) belongs to the graph.

21. Which relation represents a function?

A relation is a function when each input has exactly one output. In B), 1, 2, and 3 each have exactly one output.

22. Let f(x) = 2x + 1 and g(x) = x − 3. What is f(2) + g(2)?

f(2) = 2(2) + 1 = 5. Also, g(2) = 2 − 3 = −1. Therefore, f(2) + g(2) = 5 + (−1) = 4.

23. Let f(x) = 2x + 1. If f(a) = f(5), what is a?

f(a) = 2a + 1 and f(5) = 11. Thus, 2a + 1 = 11, giving a = 5.

24. Let A = {1, 2, 3} and B = {2, 4}. A relation R is defined by y = x + 1. Which ordered pairs belong to R?

We need y = x + 1, with x from A and y from B. For x = 1, y = 2, giving (1, 2). For x = 3, y = 4, giving (3, 4). Therefore, the correct set is {(1, 2), (3, 4)}.

25. Let A = {1, 2, 3} and B = {2, 4, 6}. A relation R from A to B is defined by y = 2x. What is the range of R?

Using y = 2x: x = 1 gives y = 2, x = 2 gives y = 4, and x = 3 gives y = 6. Therefore, the range is {2, 4, 6}.
