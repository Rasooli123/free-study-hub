Chapter 9: Numbers

Practice questions based on the chapter.

1. Which of the following is an irrational number?

√2 cannot be expressed as a ratio of two integers, so it is irrational. The other numbers are rational.

2. Which of the following is a rational number?

0.375 is a terminating decimal, so it can be written as a fraction: 0.375 = 3/8. Therefore, it is rational.

3. Which interval contains √50?

Since 7² = 49 and 8² = 64, we have 7 < √50 < 8.

4. Which of the following is the greatest number?

√20 ≈ 4.47, √18 ≈ 4.24, and 13/3 ≈ 4.33. Therefore, 4.5 is the greatest.

5. If x = √3 + 1, what is x − 1?

x = √3 + 1. Therefore: x − 1 = √3.

6. Which of the following numbers lies between 2 and 3?

Since 2² = 4 and 3² = 9, a square root lies between 2 and 3 when its radicand is between 4 and 9. Since 4 < 8 < 9, √8 lies between 2 and 3.

7. What is |−7| + |3|?

|−7| = 7 and |3| = 3. Therefore: 7 + 3 = 10.

8. If |x| = 9, what is the sum of all possible values of x?

|x| = 9 gives x = 9 or x = −9. Their sum is: 9 + (−9) = 0.

9. Which number is closest to √30?

√30 ≈ 5.477. Therefore, 5.5 is the closest number.

10. If a = 3 and b = −5, what is |a − b|?

a − b = 3 − (−5) = 8. Therefore, |a − b| = 8.

11. Which number lies between −3 and 2?

−1 is greater than −3 and less than 2. Therefore, −1 lies between them.

12. If x < 0 and |x| = 12, what is x?

Since |x| = 12, x can be 12 or −12. But x < 0, so x = −12.

13. If x = −2 and y = 5, which value is greatest?

x = −2, y = 5, |x| = 2 and −y = −5. Therefore, the greatest value is y = 5.

14. What is the value of (−3)² − 2³?

(−3)² = 9 and 2³ = 8. Therefore: 9 − 8 = 1.

15. Which of the following is equal to √72?

√72 = √(36 × 2) = 6√2.

16. If x = √5 and y = √20, which statement is true?

√20 = √(4 × 5) = 2√5. Since x = √5, we have y = 2x.

17. Which of the following is the smallest?

√7 ≈ 2.646, 2.7 = 2.7, 8/3 ≈ 2.667, and 2.6 = 2.6. Therefore, 2.6 is the smallest.

18. If |x − 4| = 7, what are the possible values of x?

|x − 4| = 7 gives: x − 4 = 7 or x − 4 = −7. Therefore: x = 11 or x = −3.

19. If x is an integer and −2 < x ≤ 4, how many possible values can x have?

The integer values are: −1, 0, 1, 2, 3 and 4. Therefore, there are 6 possible values.

20. Which expression is always non-negative?

The square of any real number is always greater than or equal to zero. Therefore, x² is always non-negative.

21. If a = √2 and b = √8, what is a + b?

√8 = 2√2. Therefore: √2 + 2√2 = 3√2.

22. If x = −3, what is |x|² + x²?

|−3| = 3, so |−3|² = 9. Also, (−3)² = 9. Therefore: 9 + 9 = 18.

23. If x and y are positive numbers and x < y, which statement must be true?

For positive numbers, squaring preserves the order. Since x < y, we have x² < y².

24. If √x = 5, what is x?

If √x = 5, square both sides: x = 25.

25. If x = √3 − 1, what is x² + 2x?

x = √3 − 1. x² = (√3 − 1)² = 3 − 2√3 + 1 = 4 − 2√3. Also: 2x = 2√3 − 2. Therefore: x² + 2x = (4 − 2√3) + (2√3 − 2) = 2.
