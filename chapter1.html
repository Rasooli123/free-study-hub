Chapter 1: Basic Concepts

Practice questions based on the chapter.

Question 1

Which of the following numbers is irrational?

√2 cannot be written as a fraction of two integers, so it is irrational.

Question 2

Which of the following is a natural number?

7 is a positive integer, so it is a natural number.

Question 3

Which of the following numbers is an integer but not a natural number?

-3 is an integer, but it is negative and therefore is not a natural number.

Question 4

Which of the following is a rational number?

0.125 is a terminating decimal, so it can be written as a fraction: 125/1000 = 1/8.

Question 5

What is the absolute value of -12?

The absolute value represents distance from zero. Therefore, |-12| = 12.

Question 6

If x = -4, what is the value of |x| + x?

|-4| + (-4) = 4 - 4 = 0.

Question 7

Which of the following is the greatest number?

Every negative number is less than zero, so 0 is the greatest number among the choices.

Question 8

Which statement is true?

Natural numbers are a subset of the integers, so every natural number is an integer.

Question 9

What is the result of (-8) + 13?

-8 + 13 = 5.

Question 10

What is the result of (-6) × (-4)?

The product of two negative numbers is positive: (-6)(-4) = 24.

Question 11

What is the result of 18 ÷ (-3)?

A positive number divided by a negative number gives a negative result: 18 ÷ (-3) = -6.

Question 12

Which expression is equal to 3² + 4²?

3² + 4² = 9 + 16 = 25.

Question 13

If a = 5 and b = -2, what is a - b?

a - b = 5 - (-2) = 5 + 2 = 7.

Question 14

Which of the following is NOT a rational number?

√11 is irrational because 11 is not a perfect square.

Question 15

What is the value of |5 - 12|?

5 - 12 = -7, and |-7| = 7.

Question 16

Which number lies between 2 and 3?

Since 4 < 5 < 9, we have 2 < √5 < 3.

Question 17

If x is a positive integer and x < 6, which of the following could be x?

The positive integers less than 6 are 1, 2, 3, 4, and 5.

Question 18

What is the value of 2(3 + 4) - 5?

First calculate the parentheses: 3 + 4 = 7. Then 2 × 7 - 5 = 14 - 5 = 9.

Question 19

Which of the following has the smallest value?

-3/2 = -1.5, which is smaller than -0.5, 0, and 0.5.

Question 20

If |x| = 7, which of the following could be x?

If |x| = 7, then x can be 7 or -7. Therefore, -7 is a possible value.

Question 21

Which of the following is equal to 0?

A number plus its opposite is zero: -4 + 4 = 0.

Question 22

If a = -3 and b = 4, what is a × b?

A negative number multiplied by a positive number gives a negative result: (-3)(4) = -12.

Question 23

Which of the following is equal to 1?

Any nonzero number raised to the power of 0 equals 1. Therefore, 5⁰ = 1.

Question 24

Which of the following is greater than 0 but less than 1?

0.6 is greater than 0 and less than 1.

Question 25

If x = -2, what is x² + |x|?

x² + |x| = (-2)² + |-2| = 4 + 2 = 6.
