MATHEMATICS 2

Limits

Chapter 10 · 25 Questions

1. Find limₓ→₂ (3x + 1).

Polynomials are continuous, so substitute x = 2: 3(2) + 1 = 7.

2. Find limₓ→₃ x².

Direct substitution gives 3² = 9.

3. Find limₓ→₂ (x² − 4)/(x − 2).

Factor x² − 4 = (x − 2)(x + 2). After cancellation, the limit is 2 + 2 = 4.

4. Find limₓ→₁ (x² − 1)/(x − 1).

x² − 1 = (x − 1)(x + 1). The remaining expression approaches 2.

5. In radians, find limₓ→₀ (sin x)/x.

The fundamental trigonometric limit is limₓ→₀ sin x/x = 1.

6. In radians, find limₓ→₀ (1 − cos x)/x².

This standard limit equals 1/2.

7. Find limₓ→₄ (√x − 2)/(x − 4).

Rationalize: the expression becomes 1/(√x + 2). At x = 4 it is 1/4.

8. Find limₓ→₀ [√(1 + x) − 1]/x.

Rationalizing gives 1/[√(1 + x) + 1], which approaches 1/2.

9. Find limₓ→₃ (x² − 9)/(x − 3).

Factor x² − 9 = (x − 3)(x + 3). The limit is 3 + 3 = 6.

10. Find limₓ→₋₁ (x² + 3x + 2)/(x + 1).

Factor the numerator as (x + 1)(x + 2). The remaining factor approaches 1.

11. Find limₓ→₀ (2x² + x)/x.

For x ≠ 0, (2x² + x)/x = 2x + 1, which tends to 1.

12. Find limₓ→∞ (3x + 1)/(x − 2).

For equal highest degrees, the limit is the ratio of leading coefficients: 3/1 = 3.

13. Find limₓ→∞ (2x² + 1)/(x² − 4).

The leading terms dominate, so the limit is 2x²/x² = 2.

14. Find limₓ→∞ 5x/(x² + 1).

The denominator has higher degree than the numerator, so the fraction tends to 0.

15. Find limₓ→₋₂ (x² + 5x + 6)/(x + 2).

x² + 5x + 6 = (x + 2)(x + 3). The remaining factor approaches 1.

16. Find limₓ→₁ (x³ − 1)/(x − 1).

x³ − 1 = (x − 1)(x² + x + 1). At x = 1, the result is 3.

17. Find limₓ→₀ |x|/x.

The left-hand limit is −1 and the right-hand limit is 1, so the two-sided limit does not exist.

18. Find limₓ→₀ x sin(1/x).

Because |sin(1/x)| ≤ 1, |x sin(1/x)| ≤ |x|, which tends to 0.

19. Find limₓ→∞ (4x² − 1)/(2x² + 3).

The ratio of leading coefficients is 4/2 = 2.

20. In radians, find limₓ→₀ sin(3x)/x.

Write sin(3x)/x = 3·[sin(3x)/(3x)]. The bracket tends to 1, so the limit is 3.

21. In radians, find limₓ→₀ tan x/x.

The standard trigonometric limit is tan x/x = 1 as x approaches 0.

22. Find limₓ→₁ (|x| − 1)/(x − 1).

Near x = 1, x is positive, so |x| = x. The expression is (x − 1)/(x − 1) = 1.

23. Find limₓ→₀ [1/(x + 1) − 1]/x.

Combine the numerator: [1 − (x + 1)]/(x + 1) = −x/(x + 1). Dividing by x gives −1/(x + 1), approaching −1.

24. Find limₓ→₂ (x² − x − 2)/(x − 2).

x² − x − 2 = (x − 2)(x + 1). The limit is 2 + 1 = 3.

25. Find limₓ→∞ (x² + 2x)/(3x² − x).

The leading coefficient ratio is 1/3.
