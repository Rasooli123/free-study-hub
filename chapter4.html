Chapter 4: Exponential Expressions

Practice questions based on the chapter.

1. What is the value of 2⁵?

2⁵ = 2 × 2 × 2 × 2 × 2 = 32.

2. Simplify: 3⁴ × 3²

When multiplying powers with the same base, add the exponents: 3⁴ × 3² = 3⁴⁺² = 3⁶.

3. Simplify: 7⁸ ÷ 7³

When dividing powers with the same base, subtract the exponents: 7⁸ ÷ 7³ = 7⁸⁻³ = 7⁵.

4. What is the value of 5⁰ + 2³?

Any nonzero number raised to the zero power equals 1. Therefore, 5⁰ + 2³ = 1 + 8 = 9.

5. Simplify: (2³)⁴

When a power is raised to another power, multiply the exponents: (2³)⁴ = 2³×⁴ = 2¹².

6. Simplify: 4³ × 4⁻¹

Add the exponents because the bases are the same: 4³ × 4⁻¹ = 4³⁻¹ = 4².

7. Which fraction is equal to 2⁻³?

A negative exponent means the reciprocal: 2⁻³ = 1/2³ = 1/8.

8. Simplify: (3² × 3⁵) ÷ 3⁴

First add the exponents when multiplying: 3² × 3⁵ = 3⁷. Then subtract 4: 3⁷ ÷ 3⁴ = 3³.

9. Which is greater?

2⁶ = 64, while 3⁴ = 81. Therefore, 3⁴ is greater.

10. If 2ˣ = 32, what is x?

Since 32 = 2⁵, we have 2ˣ = 2⁵. Therefore, x = 5.

11. If 3ˣ = 81 and 2ʸ = 16, what is x + y?

81 = 3⁴, so x = 4. Also, 16 = 2⁴, so y = 4. Therefore, x + y = 8.

12. If (x³)² = x⁶, which exponent rule is being used?

When a power is raised to another power, the exponents are multiplied: (x³)² = x³×² = x⁶.

13. Simplify: x⁷ ÷ x²

For division with the same base, subtract the exponents: x⁷ ÷ x² = x⁷⁻² = x⁵.

14. Simplify: (2x²)³

Raise both the coefficient and x to the third power: (2x²)³ = 2³ × (x²)³ = 8x⁶.

15. What is the value of (-2)⁴ − (-2)³?

(-2)⁴ = 16 and (-2)³ = -8. Therefore, 16 − (-8) = 24.

16. If 2ˣ × 2³ = 2⁹, what is x?

Add the exponents: 2ˣ × 2³ = 2ˣ⁺³. Therefore, x + 3 = 9, so x = 6.

17. If 5ˣ ÷ 5² = 125, what is x?

125 = 5³. Therefore, 5ˣ⁻² = 5³, so x − 2 = 3. Hence, x = 5.

18. Simplify: (a³b²)(a²b⁴)

Add exponents of the same variables: a³ × a² = a⁵ and b² × b⁴ = b⁶. Therefore, the result is a⁵b⁶.

19. If 4ˣ = 2⁶, what is x?

Since 4 = 2², we have: 4ˣ = (2²)ˣ = 2²ˣ. Therefore, 2x = 6 and x = 3.

20. Which expression is equal to 1/2⁵?

By the negative exponent rule, 1/2⁵ = 2⁻⁵.

21. If x = 2³ and y = 2², what is x²/y?

x² = (2³)² = 2⁶. Since y = 2², x²/y = 2⁶ ÷ 2² = 2⁴ = 16.

22. Simplify: (x⁴y³)/(x²y)

Subtract the exponents of matching variables: x⁴ ÷ x² = x² and y³ ÷ y = y². Therefore, the result is x²y².

23. If 9ˣ = 27, what is x?

Rewrite both numbers using base 3: 9 = 3² and 27 = 3³. Thus, (3²)ˣ = 3³, so 2x = 3. Therefore, x = 3/2.

24. If 2ᵃ = 8 and 2ᵇ = 32, what is a + b?

8 = 2³, so a = 3. 32 = 2⁵, so b = 5. Therefore, a + b = 3 + 5 = 8.

25. If 2ˣ + 2ˣ = 64, what is x?

2ˣ + 2ˣ = 2 × 2ˣ = 2ˣ⁺¹. Therefore, 2ˣ⁺¹ = 64 = 2⁶. So x + 1 = 6, giving x = 5.
